FAQ

Utixo Copilot è attivo 24/7?

Sì, puoi usarlo in qualsiasi momento. Se accedi, le chat vengono salvate nel tuo profilo.

Posso rivedere le chat passate?

Sì: effettua l’accesso e la lista chat sarà visibile a sinistra nel Copilot.

È possibile aggiungere nuove FAQ?

Sì, tramite la sezione admin puoi aggiornare e ampliare il database delle FAQ.
